# Lab5 — Dataset Explorer

Веб-приложение на **NiceGUI** для работы с аннотированным датасетом изображений
(классы `bay_horse` и `zebra`). Позволяет просматривать изображения, создавать
и перемешивать аннотации, а также выполнять 10 учебных заданий по анализу
датасета (статистика, фильтрация, гистограммы каналов).

## Что делает приложение

Приложение состоит из трёх страниц.

### Главная страница `/`

- Просмотр изображений по классам: кнопки **«Next zebra»** и **«Next bay horse»**
  листают изображения соответствующего класса.
- Переключатель **Loop** — включает режим зацикливания: после последнего
  изображения итератор возвращается к первому (иначе после последнего
  изображение пропадает).
- Кнопки перехода на форму работы с датасетом (`/dataset-form`) и на
  лабораторную работу (`/Lab4`).

### Страница `/dataset-form`

Две независимые формы:

- **Создать аннотацию** — рекурсивно обходит указанную папку датасета,
  извлекает метку класса из имени файла и пишет CSV-файл аннотации
  с колонками `absolute_path; relative_path; class_label`
  (разделитель `;`, кодировка `utf-8-sig` — корректно открывается в Excel).
- **Перемешать** — берёт исходный датасет, переименовывает каждый файл в
  случайное число из диапазона `NUM_RANGE = (0, 2000)` (без повторов),
  складывает результат в новую папку (по умолчанию **копированием**) и
  пишет новую аннотацию с дополнительным столбцом `number`.
  Случайность воспроизводима благодаря `SEED = 42`.

### Страница `/Lab4` — 10 учебных заданий

Каждое задание запускается отдельной кнопкой «Выполнить», результаты
сохраняются в состоянии страницы. Задания 3–10 зависят от результатов
предыдущих.

| # | Задание | Что делает | Зависит от |
|---|---------|-----------|-----------|
| 1 | DataFrame из аннотации | Читает `annotation.csv` в `pandas.DataFrame`, показывает колонки и первые 5 строк | — |
| 2 | Нормализация имён колонок | `strip().lower().replace(' ', '_')`, оставляет только `class_label` и `absolute_path` | 1 |
| 3 | Числовые метки классов | Добавляет `class_id` через `pd.Categorical` (порядок: `bay_horse`=0, `zebra`=1) | 1 |
| 4 | Размеры изображений | Читает `height`, `width`, `depth` каждого файла через `cv2.imread` | 1 |
| 5 | Статистика размеров и баланс | `describe()`, медиана, мода, IQR, сводка по классам, столбчатая диаграмма и круговая диаграмма, вердикт о балансе | 4 |
| 6 | `filter_by_class` | Оставляет строки одного класса | 2 |
| 7 | `filter_by_class_and_size` | Фильтр по классу и `height ≤ max_height`, `width ≤ max_width` | 4 |
| 8 | Статистика по пикселям | `height*width*depth`, `groupby`-агрегаты, `pivot_table`, примеры изображений (5 шт.), boxplot распределения пикселей | 4 |
| 9 | Гистограммы каналов | Для каждого класса случайно выбирает по одному изображению и строит `cv2.calcHist` по каналам B/G/R (256 бинов, нормировка на число пикселей) | 1 |
| 10 | Отрисовка гистограмм | Строит `matplotlib`-графики B/G/R для обоих классов | 9 |

## Используемые библиотеки

| Библиотека | Назначение в проекте |
|------------|---------------------|
| **nicegui** | Веб-UI: страницы (`@ui.page`), кнопки, чекбоксы, таблицы (`ui.table.from_pandas`), изображения (`ui.image`), реактивные привязки (`bind_source_from`) |
| **pandas** | Чтение/запись `annotation.csv`, `DataFrame`, `groupby`, `pivot_table`, `describe`, `Categorical` |
| **numpy** | Массивы гистограмм, `np.arange`, `np.random.default_rng` |
| **opencv-python (`cv2`)** | Чтение изображений (`imread`), `calcHist`, ресайз (`resize`), `imencode` для data URL |
| **matplotlib** | Графики (backend `Agg`, результат встраивается как PNG data URL) |
| **pathlib / shutil / os / csv** | Работа с файловой системой, копирование, перемешивание |
| **base64 / io** | Кодирование PNG в data URL для встраивания в HTML |
| **fastapi / uvicorn / starlette** | ASGI-стек под капотом NiceGUI |
| **aiofiles / aiohttp / websockets** | Асинхронный ввод-вывод и WebSocket-соединения NiceGUI |

> ⚠️ **Важно про `requirements.txt`.** Текущий файл содержит версии,
> которых нет в PyPI (например, `pandas==3.1.0`, `numpy==2.5.4`,
> `python-dateutil==4.0.0`, `opencv-python==5.0.0.93`, `fastapi==0.162.0`).
> Перед сборкой Docker-образа или установкой в чистом окружении пересоберите
> файл по факту рабочего окружения:
>
> ```bash
> pip install nicegui pandas numpy opencv-python matplotlib
> pip freeze > requirements.txt
> ```

## Структура проекта

```
Lab5/
├── annotation.csv               # исходная аннотация (sep=';', utf-8-sig)
├── dataset/                     # изображения (bay_horse_XXXX.jpg, zebra_XXXX.jpg)
├── main_window.py               # точка входа NiceGUI, все страницы
├── build_annotation.py          # построение аннотации из папки
├── shuffle_dataset.py           # перемешивание + переименование + аннотация
├── dataset_iterator.py          # итератор по классу (с loop/reset)
├── zebra.py                     # готовый DatasetIterator для 'zebra'
├── bay_horse.py                 # готовый DatasetIterator для 'bay_horse'
├── get_image_info.py            # height/width/depth одного файла
├── get_channel_histograms.py    # гистограммы B/G/R одного изображения класса
├── filter_by_class.py           # фильтры по классу / классу+размеру
├── Dockerfile
├── requirements.txt
└── ReadMe.md
```

### Назначение модулей

- **`main_window.py`** — точка входа. Содержит:
  - `fig_to_data_url()` — matplotlib Figure → PNG data URL.
  - `cv2_to_data_url()` — OpenCV BGR-изображение → PNG data URL (с ресайзом до `max_width`).
  - `State` — глобальное состояние главной страницы (текущие пути `zebra`/`bay_horse`, флаг `loop`).
  - `@ui.page('/')`, `@ui.page('/dataset-form')`, `@ui.page('/Lab4')` — три страницы.
- **`build_annotation.py`** — `build_annotation(dataset_dir, annotation_file)`:
  рекурсивный обход папки, извлечение класса из имени файла, запись CSV.
- **`shuffle_dataset.py`** — `shuffle_dataset(dataset_dir, shuffled_dir, annotation_file)`:
  копирование/перемещение файлов с новыми именами-числами, запись CSV с `number`.
- **`dataset_iterator.py`** — класс `DatasetIterator` с методами `__next__`,
  `set_loop`, `reset`.
- **`get_image_info.py`** — `get_image_info(path)` → `(height, width, depth)`.
- **`get_channel_histograms.py`** — `get_channel_histograms(df, class_label, bins, seed)`:
  случайный выбор изображения класса, `cv2.calcHist` по каналам B/G/R.
- **`filter_by_class.py`** — `filter_by_class(df, class_label)` и
  `filter_by_class_and_size(df, class_label, max_height, max_width)`.

## Установка и запуск

### Локально

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Убедиться, что рядом с main_window.py есть dataset/ и annotation.csv
#    (если annotation.csv нет — создать через /dataset-form после запуска)

# 3. Запустить
python main_window.py

# 4. Открыть в браузере
#    http://localhost:8080
```

### Docker

```bash
docker build -t lab5 .
docker run -d \
  --name lab5 \
  -p 8080:8080 \
  lab5
```

Монтирование `dataset/` и `annotation.csv` обязательно — иначе контейнер
запустится с пустыми данными (файлы из образа не обновляются при изменении
на хосте).

Альтернатива — `docker-compose.yml`:

```yaml
services:
  lab4:
    build: .
    ports:
      - "8080:8080"
    volumes:
      - ./dataset:/app/dataset
      - ./annotation.csv:/app/annotation.csv
    restart: unless-stopped
```

## Мини-гайд для пользователя

### 1. Построение аннотации

1. Запустите приложение и откройте `/dataset-form`.
2. В первой строке введите:
   - путь до датасета: `dataset`
   - имя файла аннотации: `annotation.csv`
3. Нажмите **«Создать аннотацию»**.
4. В корне проекта появится `annotation.csv` с колонками
   `absolute_path; relative_path; class_label`.

### 2. Просмотр изображений

На главной странице `/`:

- **Next zebra** / **Next bay horse** — следующее изображение класса.
- **Loop** — включить цикл. Без него после последнего изображения
  картинка пропадает (итератор бросает `StopIteration`).

### 3. Лабораторная работа `/Lab4`

Выполняйте задания **по порядку** — каждое следующее использует результаты
предыдущих. Каждое задание запускается кнопкой «Выполнить», статус
показывается иконкой:

- ✅ — выполнено успешно;
- ⚠️ — не хватает данных (сначала выполните предыдущее задание);
- ❌ — ошибка (текст ошибки выводится в блоке результатов).

Порядок зависимостей:

```
Задание 1 ──► 2 ──► 6
          ├──► 3
          ├──► 4 ──► 5
          │        ├──► 7
          │        └──► 8
          └──► 9 ──► 10
```

**Важно:** состояние `/Lab4` хранится **в памяти вкладки**. Обновили
страницу — начинайте с задания 1. Закрытие вкладки тоже сбрасывает состояние.

### 5. Перемешивание датасета

На `/dataset-form`, вторая строка:

- путь до датасета: `dataset`
- имя новой папки: `dataset_shuffled`
- имя новой аннотации: `annotation_shuffled.csv`

Нажмите **«Перемешать»**. Поведение:

- файлы **копируются** (по умолчанию `COPY_FILES = True`) в новую папку
  с именами `<случайное_число>.jpg`;
- в новой аннотации появляется столбец `number`;
- распределение по классам выводится в консоль.

Чтобы **перемещать** файлы (исходный датасет опустеет), поставьте
`COPY_FILES = False` в `shuffle_dataset.py`.

### 6. Запуск в Docker

```bash
docker build -t lab5 .
docker run -d \
  --name lab5 \
  -p 8080:8080 \
  lab5

```

Откройте http://localhost:8080.

## Ограничения

| # | Ограничение | Как обойти |
|---|-------------|-----------|
| 1 | Классы в задании 3 захардкожены: `['bay_horse', 'zebra']` | Отредактировать список в `main_window.py` (`run_task_3`) |
| 2 | `State` инициализируется `next(zebra)` при старте — падение, если `annotation.csv` пуст или в нём нет класса | Обернуть в `try/except StopIteration` в `main_window.py` |
| 3 | Состояние `/Lab4` хранится в памяти воркера и теряется при перезагрузке вкладки | Выполнять задания заново после обновления; либо вынести `df` в `app.storage` |
| 4 | `NUM_RANGE = (0, 2000)` — максимум 2001 файл при перемешивании | Увеличить диапазон в `shuffle_dataset.py` |
